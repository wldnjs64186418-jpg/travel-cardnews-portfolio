## 만든 방법

- Claude Design 프로젝트에서 카드뉴스를 제작하고, 공개 아티팩트 링크로 발행했습니다.
- 여행 카드뉴스 기획과 문구는 `travel-cardnews` 에이전트(Claude Code)의 지침을 따랐습니다.
- 위 HTML 파일은 공개 링크의 페이지를 그대로 저장한 것입니다. 이미지와 스타일이 파일 안에 들어 있어서 인터넷 연결 없이도 열립니다.

## 유의사항

- 포트폴리오용 연습 작업물입니다. 가격, 일정 같은 수치는 실제 판매 정보와 다를 수 있으니, 실제 상품 정보는 각 공식 판매 페이지를 확인하세요.
- 상품명과 브랜드명의 권리는 각 사에 있습니다.
